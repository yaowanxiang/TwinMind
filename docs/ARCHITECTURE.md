# TwinMind 技术架构

## 一、总体设计：六大系统闭环

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ ①摄入系统 │──▶│ ②画像系统 │──▶│ ③优化系统 │──▶│ ④决策评估 │──▶│ ⑤授权执行 │──▶│ ⑥反馈评估 │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
     ▲                                                                │
     └────────────── 自主学习 · 自主迭代 · 不断进化 ────────────────────┘
```

- 各模块**可独立进化**，也可**整体进化**
- 上游产出 → 下游消费，信息在上下游之间交接
- 吸收全网络的先进方法，最终服务于"把问题解决得更好"

## 二、模块详解

### ① 摄入系统（recorder/ + multimodal/）

| 子模块 | 说明 |
|---|---|
| `hermes_importer.py` | 直读 Hermes state.db（sessions+messages 表），自动探测 Win/macOS/Linux 路径 |
| `jsonl_importer.py` | 通用 JSONL/JSON：任何 AI 工具的会话都能导入（兼容 OpenAI content 数组） |
| `journal.py` | 日记入口：普通用户用大白话记录"今天做了什么、怎么做的" |
| `multimodal/ingest.py` | 图片（vision LLM 描述）/ 音频视频（faster-whisper 可选）/ 录屏（跨平台截图）→ 统一文字事件 |

### ② 画像系统（profile/）

三级抽象聚合：
- **L1 具体做法**：完成了什么
- **L2 思路模式**：可复用的思路/方法（去场景化）
- **L3 处事原则**：最高抽象，像格言，跨行业成立

画像字段：domains（领域聚类）/ principles（L3 去重加权）/ patterns（L2）/ preferences（偏好提取）/ tools / strengths / summary（LLM 或本地生成）

### ③ 优化系统（advisor/）—— 灵魂

六大能力：第一性原理 / 画像匹配 / 时空矩阵 / 学科交叉 / 四极一击 / 方案评估。

智慧库检索：中文二元组 + **概念扩展表**（"推广"→借势/人脉/营销/联盟…），无 LLM 时本地引擎兜底。

### ④ 决策评估

三方案评分：沿用旧做法 / 第一性原理重推 / 借鉴智慧组合方案，各有优缺与分数。

### ⑤ 授权执行（safety/ + executor/）

四道闸门：**策略分级 → 恶意防护 → 授权检查 → 审计留痕**

```
策略层：动作注册表 + 风险分级 R0本地只读 / R1本地写入 / R2对外通信 / R3高影响
防护层：危险命令正则库 + 敏感意图词表（防提示注入）+ 密钥脱敏
授权层：auto全自动 / semi半自动 / manual人工主导；R3 任何模式强制审批
审计层：audit_log 只增不改
```

审批通过后 `execute_approved()` 才真正执行动作。

### ⑥ 反馈评估

用户认可度/评语 → 写回画像 feedback 数组 → 进化信号。

## 三、数据模型（SQLite）

| 表 | 用途 |
|---|---|
| sessions | 会话（来源：hermes/jsonl/journal） |
| events | 原始事件流（消息/操作） |
| patterns | 三级抽象记忆（level 1/2/3） |
| profile | 数字画像（单行 JSON） |
| advices | 历史建议 |
| pending_approvals | 审批队列 |
| audit_log | 审计日志 |
| kv | 键值配置 |

## 四、技术选型

- 核心引擎：**纯 Python 标准库**（零第三方依赖，保证开箱即用）
- 存储：SQLite（单文件，本地优先，隐私友好）
- Web：FastAPI + uvicorn（可选）
- 桌面：pywebview（可选）
- 打包：PyInstaller + GitHub Actions 三平台矩阵
- LLM：OpenAI 兼容协议（智谱/DeepSeek/MiniMax/Ollama 通用），无 Key 自动降级本地引擎
