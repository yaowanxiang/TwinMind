# 开源了 TwinMind：一个会"偷学"你处事方式的 AI 分身

最近做了一个开源项目 **TwinMind**（数字画像·处事智慧引擎），想跟大家聊聊。

**痛点**：现在的 AI 助手都不"懂你"。每次都要重新交代背景，给的建议永远是标准答案，不会记得你踩过的坑。

**思路**：让 AI 先学习"你怎么做事"，再帮你做事。

## 核心设计

1. **三级抽象蒸馏**：把你的言行提炼成 做法(L1) → 思路(L2) → 原则(L3)。L3 就是你的数字画像——放到任何行业都成立的处事原则。

2. **人类智慧库（时空矩阵×学科交叉）**：内置 67 条人类顶级智慧。你问"怎么推广开源项目"，它给你讲草船借箭（借势）、合纵连横（联盟）；问"团队效率低"，它讲精益思想和"少则得"。

3. **第一性原理重构**：抛开你过去的操作习惯，从问题本质重新推演方案——往往更短更省更有效。

4. **安全**：风险分级(R0-R3) × 三种授权模式（全自动/半自动/人工主导）× 恶意指令拦截 × 审计留痕。**一切对外动作必须你批准。**

## 实测

导入 12 个真实 AI 会话 → 1,753 条事件 → 蒸馏 196 条记忆 → 自动识别领域（软件开发/科研/写作/金融投资）。问"如何推广"→ 智慧库给出借力/借势/联盟/群体智能，比我自己的方案高一维。

## 上手

```bash
pip install -r requirements.txt
twinmind record --hermes && twinmind distill
twinmind ask "你的问题"
twinmind server --desktop   # 中文桌面界面，傻瓜化
```

无 LLM Key 也能用（内置本地引擎），配了 Key 质量大幅提升。
