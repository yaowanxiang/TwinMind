# TwinMind 开源：让 AI 从"回答问题"进化到"懂你怎么做事"

> 数字画像 × 记忆蒸馏 × 时空智慧库 —— 一个面向所有人的"处事智慧引擎"

## 一、背景：AI 助手的最后一公里，是"懂你"

2026 年的今天，人人都有 AI 助手。但用过的人都知道那种割裂感：

- **无状态**：每次对话都要重新交代"我是谁、我在做什么项目、我偏好什么"
- **标准答案**：AI 给的是通用解法，不是"你的解法"
- **不复盘**：你上周踩过的坑，这周它照样让你踩

行业里已有 screenpipe（录屏记忆）、claude-mem（会话压缩）等优秀工具，但它们解决的是"**记录**"问题。**TwinMind 想解决的是"理解"问题**：从你的行为中提炼你的处事原则，再用全人类的智慧帮你更高维解题。

## 二、架构：六大系统闭环

```
摄入系统 → 画像系统 → 优化系统 → 决策评估 → 授权执行 → 反馈评估
    ↑                                                  │
    └────────── 自主学习 · 自主迭代 · 不断进化 ──────────┘
```

每个模块可独立进化，也可整体进化。

### 1. 摄入系统（多模态）

- `recorder/hermes_importer.py`：直接读取 Hermes state.db（sessions + messages 表），自动探测 Windows/macOS/Linux 路径
- `recorder/jsonl_importer.py`：通用 JSONL/JSON，任何 AI 工具的会话都能进
- `multimodal/ingest.py`：图片（vision LLM 描述）、音频/视频（faster-whisper 转写，可选）、录屏（跨平台截图）

### 2. 蒸馏系统（三级抽象）

```python
# distill/distiller.py 的核心思想
L1 具体做法    → "用 Python 完成了数据清洗"
L2 思路模式    → "先搭框架再填细节，分步验证"（去场景化，可迁移）
L3 处事原则    → "追求彻底完成，不留尾巴"（最高抽象，像格言）
```

有 LLM 时走大模型结构化蒸馏（JSON mode），无 Key 时自动降级本地启发式（关键词+句法规则），保证开箱即用。

### 3. 画像系统

聚合三级抽象 → 领域识别（关键词聚类）/ 原则库（去重加权）/ 偏好提取 / 工具统计。画像是一段持续进化的人物速写。

### 4. 优化系统（高维顾问）—— 项目灵魂

`advisor/advisor.py` 整合六大能力：

- **第一性原理**：先厘清"你的真正目标"，再抛开旧操作从本质重推
- **时空矩阵**：横向（文化）× 纵向（时代）检索人类智慧库
- **学科交叉**：博弈论/医学/工程/计算机方法论迁移
- **四极一击**：范式×尺度×状态×知识四维极值扫描 + 降维打击（吸收自四极一击创新法）
- **方案评估**：旧做法 vs 本质重推 vs 智慧组合，三方案评分
- **反馈闭环**：用户认可度写回画像

检索亮点：中文概念扩展表（"推广"→借势/人脉/营销/联盟…），大幅提升语义命中。

### 5. 授权执行系统 —— 安全架构

```
策略层：动作注册表，风险分级 R0本地只读 / R1本地写入 / R2对外通信 / R3高影响
防护层：危险命令正则库 + 敏感意图词表（防提示注入）+ 密钥脱敏
授权层：auto全自动 / semi半自动 / manual人工主导；R3 任何模式强制审批
审计层：所有动作留痕，只增不改
```

执行四道闸门：`策略分级 → 恶意防护 → 授权检查 → 审计留痕`，审批通过后 `execute_approved()` 才真正执行。

### 6. 反馈评估系统

建议是否有用、用户评语 → 写回画像（feedback 数组），成为进化的训练信号。

## 三、人类智慧库（时空矩阵 × 学科交叉）

内置 67 条原创撰写的人类智慧，两条检索轴：

| 维度 | 分布 |
|---|---|
| 文化（横向） | 中国30 / 全球16 / 美国10 / 英国3 / 日本2… |
| 时代（纵向） | 古代29（孙子兵法/史记案例/道德经）/ 近代5 / 现代29（PDCA/博弈论/精益）/ 未来3 |
| 学科 | 军事/哲学/医学/金融/计算机/统计学/管理学/物理学/生物学/经济学… 37 学科 |

每条含：essence（核心思想）+ how_to_apply（如何借鉴）+ applicable_to（适用场景）+ contrast（中外/古今对照）。

## 四、代码示例

```python
from twinmind.advisor.advisor import advise
from twinmind.recorder import journal
from twinmind.pipeline import run_pipeline

# 记录 → 蒸馏 → 画像
journal.add_journal("今天完成了项目A，我先规划再执行，最后全部跑通")
run_pipeline(limit_sessions=20)

# 高维顾问
result = advise("如何高效推广我的开源项目")
print(result["goal"])                    # 第一性原理目标
print(result["spacetime_matrix"][0])     # 时空矩阵借鉴
print(result["four_poles"]["strike"])    # 四极一击·降维打击
```

## 六、快速开始

```bash
git clone https://github.com/yaowanxiang/TwinMind.git
cd TwinMind
pip install -r requirements.txt
PYTHONPATH=. python -m twinmind.cli server --desktop
```

Windows/macOS/Linux 打包脚本已备好（`scripts/`），PyInstaller 一键出安装包。
